# Game Studio Clicker Balancing Notes

This file collects playtest observations for the dedicated balancing milestone.
These notes describe how the game currently feels; they are not proposed balance
changes yet.

## Initial playtest observations — 2026-09-05

- Workers feel much too weak compared with purchasing click-production upgrades.
- The early game feels fine.
- After roughly the first five click doublers, the next active upgrades can be
  purchased almost immediately.
- Progression slows down significantly around the Enterprise Data Center compared
  with the rapid sequence of upgrades before it.
- Having prices and production values repeatedly double makes the progression feel
  repetitive.
